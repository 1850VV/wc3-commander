# 元策略与编排

目的：我只提供最小的「元策略」（积木），每个只做一件事、参数摆在外面；你用它们自己编排整局打法。仲裁器只负责按你的编排执行，并照样记下每个决定、每条命令和游戏回报（事件流、回放、对账都不变）。

## 一、元策略（每个只做一件事）

每个元策略都有：**参数**、**启动条件**、**停止条件**、**优先级**（谁先拿人和钱）。启动后它一直运行，直到停止条件满足。

| 编号 | 元策略 | 参数 | 它做什么 |
|---|---|---|---|
| M1 | 采金 | 哪座矿（主矿 / 分矿）、人数 | 保持这座矿有这么多人采金；少了从「空闲 → 新农民 → 伐木」补，多了放回伐木 |
| M2 | 伐木 | 人数（算不算去建造的人：算） | 保持这么多人伐木；建造的人建完回来，不另补 |
| M3 | 训练农民 | 哪座基地、补给谁（采金 / 伐木 / 分矿） | 有空闲基地且对应的人数不够就训练，够了就停 |
| M4 | 建造 | 建筑、位置（封家第几格 / 自动 / 分矿旁）、建造者（指定农民 / 从伐木抽 / 从小组抽）、协助人数、完工后去哪 | 走到工地外待命，资源够就开工 |
| M5 | 训练单位 | 兵种、上限数量、在哪个建筑 | 建筑空闲且没到上限就训练 |
| M6 | 升级 | 建筑 → 目标（城镇大厅 → 主城、侦察塔 → 奥术塔） | 资源够、建筑空闲就升 |
| M7 | 学技能 | 英雄、技能 | 英雄有技能点就学 |
| M8 | 敲钟 | 人数、从哪抽（伐木 / 采金）、集合点（祭坛旁 / 指定） | 农民走到大厅变民兵，再走到集合点 |
| M9 | 清野 | 成员（英雄、步兵、民兵）、目标（本方向的分矿） | 攻击移动过去、放水元素、集火；民兵残血不管（你手动处理）；英雄 30% 血全队撤 |
| M10 | 小组 | 名字、哪些人（例如「清野后的 5 个民兵」） | 把一批人编成组，原地待命，供后面的建造指定使用 |
| M11 | 留钱 | 金、木、留给谁 | 比它优先级低的东西不准花这笔钱；但按采集速度算不会让目标更晚的，可以先花（现在的 A10） |
| M12 | 人口 | 提前量（剩几格人口就造农场）、农场位置顺序 | 快卡人口时造农场 |
| M13 | 设集结点 | 建筑、位置 | 例如英雄出生前把祭坛集结点设到城镇大厅 |

技术动作（不用你编排，自动处理）：伐木换树、走到工地外待命、不给金矿里的单位下命令、你手动操作的单位几秒内不碰。

## 二、编排：一条一行

每一行：**何时启动 → 用哪个元策略、参数 → 何时停止 → 优先级**。

启动 / 停止条件可以是：
- 时间：`0:00`、`1:30`
- 某一行开始 / 完成：`第 5 行完成`、`第 12 行开工`
- 单位或建筑出现：`大法师出生`、`兵营完成`、`农民6 出生`
- 资源：`金 ≥ 385 且 木 ≥ 205`
- 人数：`伐木 < 8`、`步兵 = 6`
- 组合：`第 9 行完成 且 金 ≥ 385`

## 四、需要你决定

1. **在哪里编排？**
   - (a) 控制台里加一个「编排」面板，表格形式，每行用下拉框选元策略和条件，可以拖动调顺序、改优先级，存成一套策略；
   - (b) 一个中文文本文件，就按上面的表格写，你直接改，我负责读进去。
   
   (a) 好用但要多做一点；(b) 最快能用上。也可以先 (b) 后 (a)。
2. **元策略清单还缺什么、哪些要拆得更细或合并？**
3. **例子里的编排，你直接在这份文件上改成你要的样子。** 改完就是第一套由你编排的打法。
