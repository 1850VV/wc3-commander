# 战术脚本

> 已实现（2026-10-20）：执行器 `bridge/commander_bridge/script_runner.py`，控制台「战术脚本」标签可视化编排（拖卡片、预演、按时间排开）。第四节的问题按默认办：语法如下；农民分工按示例；死了就停在那里标红；保留 4 个安全动作并逐条记录。

把整局打法写死成一份脚本：**位置、每个农民的一生、每座建筑的生产顺序全部固定**，程序只做两件事：照着做，以及等资源和条件满足。没有自动分配、没有兜底，脚本写什么就做什么。哪里不对，你直接改脚本。

决策记录、命令出处、对账、回放都保留；时间轴改成「每个农民一条线、每座建筑一条线」。

## 一、三样东西

### 1. 位置

先给要用到的地点起名字，后面用 `@名字` 引用。

```
位置 祭坛     = 布局.国王祭坛
位置 农场1    = 布局.农场1          # 布局文件里的第 1 个农场位置
位置 兵营     = 布局.兵营
位置 前方空地 = 祭坛 前方 400       # 祭坛往城镇大厅方向 400，避开工地
位置 分矿     = 本方向分矿          # 南方 → 左边，北方 → 右边，西方 → 上边，东方 → 下边
位置 分基地   = 分矿.城镇大厅       # 布局文件里分矿城镇大厅的位置
位置 分矿塔   = 分矿.侦察塔
位置 分矿木场 = 分矿 后方 640       # 分基地背后
位置 某处     = 坐标 1280,-6848     # 也可以直接写坐标
```

### 2. 每个农民的一生

一行一个农民（编号相同生命线的可以合写：`农民9、10、12`）。用 `→` 连起来，**按顺序一件一件做**，做完一件才做下一件。方括号里是这一步的开始条件，不写就是上一步做完马上开始。

```
农民4：建造 国王祭坛 @祭坛 → 伐木 主矿
```

动作：

| 动作 | 意思 |
|---|---|
| `采金 主矿` / `采金 分矿` | 一直采，直到被后面的条件叫走 |
| `伐木 主矿` / `伐木 分矿` | 同上（分矿的木头交到分矿的伐木场） |
| `建造 X @位置 #名字` | 走到工地外待命，资源够了开工，建完才算这一步做完；`#名字` 给这座建筑起名，别处引用 |
| `协助 #名字` | 去帮忙建那座建筑，建完才算做完 |
| `敲钟` | 走到城镇大厅变民兵 |
| `集合 @位置` | 走到那里等 |
| `清野 @位置` | 跟着清野（这一组谁参加，看谁写了这一步） |
| `待命 @位置` | 走到那里站着，等后面的条件 |
| `加入 队伍名` | 跟着这支队伍做事，直到队伍「解散」，然后接着做自己后面的步骤（见下面的「队伍」） |

条件（写在方括号里，可以用「且」连起来）：

| 条件 | 意思 |
|---|---|
| `[1:30]` | 1:30 这一步**已经在做**：按走路距离提前出发，到了就开工（例如建造在 1:30 开工） |
| `[1:30 出发]` | 1:30 才出发（控制台在红线上下的令、拖动卡片都写成这种） |
| `[上一步完成后 10 秒]` | 上一步做完再等 10 秒（采金、伐木这种一直做的步骤，从它开始算） |
| `[大法师出生前 10 秒]` | 大法师出来前 10 秒（按祭坛训练进度算） |
| `[金≥385 木≥205]` | 资源够 |
| `[#分基地 开工]` / `[#分基地 完成]` | 某座建筑开工 / 完工 |
| `[大法师 出生]` / `[大法师剩余 ≤ 集合用时]` | 英雄出生 / 敲钟倒推（集合用时由程序算出，写进记录） |
| `[清野 完成]` | 清野结束 |
| `[人口剩 ≤ 4]` | 快卡人口 |

### 队伍

几个单位一起做事：队伍自己一行，写它的步骤，最后一步是「解散」；成员在自己那一行写「加入 队伍名」。

```
队伍 清野小队：集合 @前方空地 → 清野 @分矿 → 解散
农民8：伐木 主矿 → [大法师剩余 ≤ 集合用时] 敲钟 → 加入 清野小队 → 建造 伐木场 @分矿木场
```

- 队伍的第一步等所有成员都加入了才开始（还没出生的成员也等）；之后加入的人直接接上队伍正在做的那一步。
- 队伍能做：集合、移动、攻击移动、待命、清野（跟着大法师清；队伍里有英雄时由它带队开始）、解散。
- 「加入」这一步一直持续到队伍解散；解散后成员接着做自己后面的步骤。

### 3. 每座建筑的生产顺序

一行一座建筑，`→` 连起来按顺序生产。训练出来的农民在这里**指定编号**，他的一生就是上面那一行。

```
城镇大厅：农民6 → 农民7 → 农民8 → …
国王祭坛：集结点 @前方空地 → 大法师
兵营：集结点 大法师 → 步兵 ×6
```

### 4. 花钱的先后

两件事同时等钱时，**脚本里写在前面的先拿**。另外可以写「留钱」，并且按采集速度算：只要不会让被留钱的那件事更晚，余下的钱照样先花（就是现在的 A10）。

```
留钱 金385 木205 给 #分基地 从 [清野 完成]
```

## 三、去掉哪些兜底

写死以后，下面这些自动行为都关掉，脚本没写的事程序一律不做：
- 自动分配采金、伐木人数；
- 自动补农民、自动造农场（农场写在农民的生命线里）；
- 自动训练步兵到上限；
- 自动把空闲农民派去伐木。

只保留和打法无关的安全动作，而且每次发生都写进记录，你能看到：
- 不给金矿里的单位下命令（否则游戏接口会出错）；
- 建造者走到工地外待命（站在工地上游戏不开工）；
- 树被砍光、或者游戏把伐木命令扔掉时，就近换一棵树（同一片区域）；
- 建造者停下时叫回来接着建。
