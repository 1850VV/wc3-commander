# 2026-10-19 载入布局后显示名字（界面）

**结论：在有界面的 Edge 里，从「载入布局…」选「南出生点」后，顶栏出现「当前布局 · 南出生点」，战局概览也显示一行；改出生点后出现「未保存」，点「保存」写回同一套、不弹框；「另存为…」才问名字。**

记录时间：2026-10-19 23:17–23:25（Asia/Shanghai）。服务：本仓库 `python -m commander_bridge --backend wc3env --opponent none`，`http://127.0.0.1:8790/`。

## 怎么测的

- 浏览器：Edge 155 的**有界面**窗口（独立临时用户目录），不是无头模式。
- 用 DevTools 协议对顶部下拉框派发 `focus` / `change`，等同于点选；其余都是页面自己的代码。
- 「另存为」的名字用临时的 `window.prompt` 替身返回（自动化里原生对话框会阻塞），写的是真实文件。
- 载入的是「南出生点」（14 个事件），截图见 [`ui.png`](ui.png)。

## 结果

| 步骤 | 观察到 |
|---|---|
| 载入「南出生点」 | 顶栏 `当前布局 · 南出生点`（136×23 px）；概览 `当前布局 南出生点` |
| 点「另存为…」 | 顶栏变成 `当前布局 · 临时UI-验证2`，提示「已保存到…：14 个事件」 |
| 把出生点改成西方 | 顶栏末尾出现 `未保存` |
| 点「保存」 | 不弹框，`未保存` 消失；文件里 `start` 从 0 变成 1，证明改动写回了同一套 |

## 之前为什么不显示

旧页面可能和新脚本混在一起：浏览器缓存着没有 `#planName` 的旧 `index.html`，脚本里 `getElementById('planName')` 拿到 `null`，于是什么都不显示。现在服务端对静态文件发 `cache-control: no-store`，普通刷新（不用强制刷新）就能拿到配套的 HTML/CSS/JS。
