## 发现的问题：第二个农场重复建造

| 游戏时间 | 时间轴（e9 农场·农民6） | 游戏里 |
|---|---|---|
| 53.9 | 农民 6 前往工地 | |
| 56.9 | 仍是「前往工地」 | 农场 u27136 在 (1344, −7744) 开工，距计划工地 724 |
| 92.0 | 游戏没有开工，重试 | u27136 完工（人口上限 24） |
| 100.7 | 前往工地 | 第二个农场 u26445 在 (128, −7104) 开工，距离 716 |
| 135.8 | 游戏没有开工，重试 | 第三个农场 u25862 在 (128, −6848)，距离 802 |
| 178.8 | 建造中 0%（终于认出） | 第四个农场 u25602 在 (896, −7424)，距离 202 |

计划工地是 (832, −7232)。原因（`bridge/commander_bridge/engine.py`）：

- `build` 命令带 `auto_place=True`，游戏会自己挪位置；
- `_bind_construction` 只认计划工地 700 以内的新建筑，被挪到 700 以外就跳过；
- 农民造完后没有新命令，`_advance` 看到「已下令但农民空闲」就判断没开工，扣钱重下。

结果多花 3 × 80 金、3 × 20 木。上一局（12:04 那次启动验收）e9 的开工时间也是 178.8 秒，说明在固定种子下每次都会重现。
