# 已知问题与四方向实测记录（2026-10-20）

真机（Lost Temple 1.27a）四方向实测后的一次完整记录。测试基线：模拟器 22/22、桥接 38/38；南方 2× 实时可操作、西方/北方/东方 4× stepping（无窗口）。

## 已完成

- **出生方向自适应**
  - 新增 `--human-slot 0|1|2|3`（0 南 / 1 西 / 2 北 / 3 东），动作、观测、放置/拒绝反馈都按人类槽位收发。
  - 启动时 `start` 直接取人类槽位；attach 检测到城镇大厅所在出生点后，把 `plan["start"]` 写成检测到的方向。
  - 四套布局 `start` 校正为 0/1/2/3；南方补回漏掉的 F6；南方同步为「3 人协助 + 1 人敲塔」。
  - 北方侦察塔 site 从 `[-7296,-6912]`（西方/南方）改回 `[3904,6464]`，实测建成并升级为防御塔。
- **分基地**
  - 西/北/东分基地去掉 `at`，恢复成和南方一样的游戏自动选址（原来的精确点压在自然金矿上，游戏接受命令却不落位）。
  - 预置的 4 个农民走到工地外 384 的待命点（不再站在建筑占地里），资源够了再进工地。
  - 等待资源期间为大厅保留成本（`_reserve` 现在覆盖 `running + wait_res`），农场 4、伐木场、塔升级、主城都会等它。
- **经济和上限**
  - 金矿 5 人锁定；伐木 8 人；步兵上限 6（F6）；农民目标 = 5×大厅 + 8，够了跳过训练。
  - 建造者从伐木/新农民里选，不再抓采金农民；完工回原岗位。
- **窗口模式**
  - 交互窗口 = realtime + 钩子时钟，2× 实测 2.00×，视角可自由移动；stepping 会冻结输入，只用于无人值守测试。

## 未解决

1. **北方伐木场 site 仍是 `[-6432,-3296]`（西/南方向）**：北方伐木工砍完树要横穿地图交木头，木头收入约 0.4/秒，大厅卡在 146/205。这类非墙建筑（伐木场、神秘圣地、农场 4/5 等）的 site 仍带着旧方向的数据，需要按起点整体审计。
2. **西方清野仍然超时**：上限已从 150 秒放宽到 240 秒，实测 122–363 仍失败。5 民兵 + 3 步兵 + 1 级大法师打不动西方分矿的野怪；侦察塔 225 秒建、257 秒被拆；分基地被 `after 清野` 卡住。
3. **西方/东方木头低**（72 / 5，北方同时间 226）：东、西封家墙可能挡住伐木路线；现在的封家检查只验证采金路线，没验证「大厅 → 树林/伐木场」。
4. **大厅建造者偶尔「进矿/不在场」**：自动重选在 `_advance` 里，但可能长时间拿不到可用农民（本次北方曾卡 400 多秒）。
5. `--human-slot` 目前只用于 `--launch` 测试路径；attach 的人类槽位仍从加载的游戏里隐式取得，没有显式回写。
