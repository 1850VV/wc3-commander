# 第一次实机验收（Windows）

目标：确认默认开局的五个事件能在真游戏里按计划执行，时间轴状态和游戏画面一致。

## 1. 确认 wc3env 能用

在 `wc3env-127a` 目录：

```powershell
python -m pip install -e .
python -m wc3env --instances 1 --steps 20 --stepms 250 --speed 64
```

能打印出推进结果就说明游戏路径、`wc3hook.dll` 和版本校验都正常。报错时先按 wc3env-127a 的 README 修好这一步。

## 2. 拿到指挥官代码

和 `wc3env-127a` 放在同一级目录：

```powershell
git clone https://github.com/1850VV/wc3-commander
```

## 3. 确认地图

wc3env 会在游戏的 `Maps` 目录（含子目录）里找名为 `(4)LostTemple.w3m` 的文件，**必须正好一个**：

```powershell
Get-ChildItem -Recurse -Filter "(4)LostTemple.w3m" "$env:WC3_GAME_DIR\Maps"
```

没有就从 warcraft-commander 仓库的 `maps/` 复制进 `Maps`；有两个就删掉或改名多余的那个（同名的雪地 `.w3x` 不算）。

## 4. 启动

```powershell
cd wc3-commander\bridge
python -m commander_bridge --backend wc3env
```

打开 <http://127.0.0.1:8790/>，点「连接 魔兽争霸三」。游戏窗口会弹出（后台可见模式，不会因为切到浏览器而暂停），不要关它。

## 5. 对照检查（游戏时间）

| 时间 | 应该看到 |
|---|---|
| 0–5 秒 | 农民 1、2、3 离开去建祭坛、农场、兵营；农民 4、5 采金；主基地开始训练农民 |
| 约 15 秒 | 农民 6 出生并去采金；下一个农民开始训练 |
| 约 38 秒 | 第一个农场完工，人口上限 18 |
| 约 64 秒 | 祭坛、兵营完工，建造它们的农民回去采金 |
| 约 65 秒 | 祭坛开始训练大法师（第一个英雄免费） |
| 约 75 秒 | 兵营开始训练步兵 |

每一条同时看两边：时间轴上的状态和文字，和游戏画面是否一致。

## 6. 记录结果

- 2:00 左右截一张控制台全页图，再截一张游戏画面。
- 复制启动服务的终端窗口里的全部输出。
- 控制台底部提示区出现的红字（例如「游戏拒绝了命令 build（no_build_site）」）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 找不到 wc3env | 在 wc3env-127a 里 `pip install -e .`，或启动时加 `--wc3env ..\..\wc3env-127a\src` |
| map name ... matched 0 files / 2 files | 回到第 3 步 |
| 版本或哈希校验失败 | 游戏不是 1.27.0.52240 的原版文件，wc3env 会拒绝注入 |
| 事件一直「等待资源」 | 正常的话会自己开始；超过 20 秒不动，截图时间轴和游戏资源栏 |
| 「游戏没有开工，重试」反复出现 | 选址或路径问题，截图工地附近的游戏画面 |
| 时间轴显示完工但画面没有建筑 | 记下事件名和时间，这是需要修的 bug |

停止：点控制台的「断开」，或在终端按 Ctrl+C。只在离线单机使用。
