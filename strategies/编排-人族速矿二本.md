# 编排 · 人族速矿二本

失落神庙 · 1.27a · 人族。四个出生点共用这一份编排；建筑的「布局位置」取自各出生点的布局文件（`strategies/人族速矿二本 · 南方.json` 等），分矿由程序按出生点认（南方 → 左边，北方 → 右边，西方 → 上边，东方 → 下边）。

元策略和写法见 `docs/元策略.md`。改完保存这个文件，下一局就按新的编排打。

## 写法速查

- **元策略**：`M1 采金（主矿，5 人）`、`M2 伐木（8 人）`、`M3 训练农民（任意基地）`、`M4 建造（建筑，位置，建造者，协助 N 人，完工去X）`、`M5 训练单位（兵种，N 个 / 上限 N）`、`M6 升级（A → B）`、`M7 学技能（英雄，技能）`、`M8 敲钟（N 人，从伐木抽）`、`M9 清野（…）`、`M10 小组（…）`、`M11 留钱（金 G，木 W，给第 k 行）`、`M12 人口（剩 N 格造农场）`、`M13 设集结点（A → B）`。一行里放多个，用 `＋` 连起来。
- **位置**：`布局位置`（布局文件里这种建筑的下一个位置）、`自动`、`分矿旁`、`坐标 x,y`。
- **建造者**：`农民N`、`从伐木抽`（默认）、`分矿组`（清野后留在分矿的那几个人）。
- **启动 / 停止条件**：`0:00`、`第 k 行完成`、`第 k 行开始`（建筑开工、训练/升级开始）、`大法师出生`、`兵营完成`、`农民6 出生`、`大法师出生前 自动`（按农民走路时间倒推）或 `大法师出生前 8 秒`、`金 ≥ 385`、`木 ≥ 205`、`伐木 < 8`、`步兵 = 6`；用 `且` 连接。停止写 `不停` 就一直运行；写 `完工`、`完成`、`出生`、`学会`、`清完` 就是做完自己的事为止。
- **优先级**：数字越大越先拿人和钱。留钱（M11）只挡优先级比它低的；按采集速度算不会让它更晚的，照样可以先花。
